When a tag breaks.

Tags get muddy, chewed and torn off. Every case ends the same way: the dog is found, the feeders are told, and someone reprints the same code. Reprinting uses the print screens in Register and Print.

Tag found on the ground
Scanning it opens the dog. Report it and the feeders get an alert. F4, F5.
Tag on the wrong dog
Reported from the profile. Feeds and SOS on that code pause until a feeder checks. F4.
Same code forever
Any feeder of the dog can reprint. The code never changes, so spare tags keep working. F6.
